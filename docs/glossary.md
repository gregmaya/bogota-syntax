# Glossary · Glosario

Every acronym and technical term the project uses, in English and Spanish. Issues, pull requests and docs spell out an acronym the first time it appears and can link here.

Cada sigla y término técnico del proyecto, en inglés y español. Los issues, pull requests y documentos escriben la sigla completa la primera vez y pueden enlazar aquí.

## Institutions and sources · Instituciones y fuentes

| Term · Término | English | Español |
| --- | --- | --- |
| **SDP** | Secretaría Distrital de Planeación: Bogotá's planning department | Secretaría Distrital de Planeación de Bogotá |
| **UAECD** | Unidad Administrativa Especial de Catastro Distrital: Bogotá's cadastre office (Catastro Bogotá) | Unidad Administrativa Especial de Catastro Distrital (Catastro Bogotá) |
| **IDECA** | Infraestructura de Datos Espaciales para el Distrito Capital: Bogotá's spatial data infrastructure, run by UAECD; publishes the Mapa de Referencia | Infraestructura de Datos Espaciales para el Distrito Capital, a cargo de la UAECD; publica el Mapa de Referencia |
| **MVI** | Malla Vial Integral: the street-network theme of the Mapa de Referencia (centrelines, carriageways, sidewalks) | Malla Vial Integral: el tema de red vial del Mapa de Referencia (ejes, calzadas, andenes) |
| **POT** | Plan de Ordenamiento Territorial: the city's land-use plan; Bogotá's current one is Decreto 555 de 2021 | Plan de Ordenamiento Territorial; el vigente en Bogotá es el Decreto 555 de 2021 |
| **RENOBO** | Empresa de Renovación y Desarrollo Urbano de Bogotá: the city's urban renewal company | Empresa de Renovación y Desarrollo Urbano de Bogotá |
| **SITP** | Sistema Integrado de Transporte Público: Bogotá's integrated public transport system | Sistema Integrado de Transporte Público de Bogotá |
| **GTFS** | General Transit Feed Specification: a standard format for public transport timetables and stops | Especificación estándar para horarios y paradas de transporte público |
| **OSM** | OpenStreetMap: a crowd-sourced world map | OpenStreetMap: mapa mundial colaborativo |
| **CKAN** | The open-source data portal software behind datosabiertos.bogota.gov.co; has a JSON API | Software libre del portal datosabiertos.bogota.gov.co; tiene una API JSON |

## Project · Proyecto

| Term · Término | English | Español |
| --- | --- | --- |
| **ADR** | Architecture Decision Record: a short file recording one decision and why it was made | Registro de decisión de arquitectura: un archivo corto con una decisión y su razón |
| **PMTiles** | A single-file archive of map tiles, read over HTTP range requests | Archivo único de teselas de mapa, leído mediante peticiones HTTP por rangos |
| **CRS** | Coordinate reference system | Sistema de referencia de coordenadas |
| **Live / dead nodes** | cityseer terms: live nodes are inside the study area and get results; dead nodes are in the buffer and only carry routes | Términos de cityseer: los nodos vivos están dentro del área de estudio y reciben resultados; los muertos están en el área de amortiguamiento y solo sirven para las rutas |

## Network analysis · Análisis de redes

| Term · Término | English | Español |
| --- | --- | --- |
| **Centrality** | A family of measures of how important a node or segment is within a network | Familia de medidas de qué tan importante es un nodo o segmento dentro de una red |
| **Closeness** | How near a node is to all others, by shortest paths | Qué tan cerca está un nodo de todos los demás, por caminos más cortos |
| **Betweenness** | How often a node lies on shortest paths between other pairs of nodes | Con qué frecuencia un nodo está en los caminos más cortos entre otros pares de nodos |
| **Space syntax** | A set of theories and methods that relate the spatial configuration of streets to movement and land use | Conjunto de teorías y métodos que relacionan la configuración espacial de las calles con el movimiento y los usos del suelo |
